Home Media Server Project

A personal, fully automated home media server built on a modest Windows 11 OptiPlex Micro. This project focuses on secure, private streaming and efficient hardware-accelerated playback for a seamless media experience.

Project Overview: STAR Summary

Situation

I aimed to build an automated home media server on a Windows 11 OptiPlex Micro, overcoming VPN security and hardware constraints.

Tools

OS & Virtualization: Windows 11, WSL2, Docker Desktop
Media & Acceleration: Jellyfin, Intel QuickSync
Privacy & Networking: Gluetun, VPN, Tailscale

Action

Deployed Docker Compose with hardlinks for data mapping, secured traffic via Gluetun and Tailscale, automated the Prowlarr-Sonarr-Radarr pipeline, and optimized Jellyfin with QuickSync.

Result

Achieved full automation of media acquisition, leak-proof network privacy via VPN, remote Tailscale streaming, and efficient hardware playback.

Technical Implementation

A methodical breakdown of the media server ecosystem

Despite the seemingly modest hardware specifications, this system remains perfectly reliable and more than sufficient for personal, light‑use home media.
System Specs

CPU: Intel Core i3-8100T @3.10 GHz
RAM: 16GB DDR4
Storage: Total 5.45 TB usable, with easy upgradability

Server Configuration

Containerization: Multi-tier Docker Compose
Security: Mulvad VPN and Tailscale for remote access
Server software: Jellyfin for easy configuration and access.
